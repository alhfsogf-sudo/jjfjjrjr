# ⚔️ سيادة الأمم — Empires of Discord

بوت Discord لعبة استراتيجية نصية كاملة، مبني بالكامل على الأزرار والقوائم التفاعلية
بدل الأوامر النصية (Slash Commands) — راجع `التقرير-الكامل.md` لشرح كل تحسين تم إضافته.

## 🚀 خطوات التشغيل

### 1) إنشاء بوت Discord
1. اذهب إلى https://discord.com/developers/applications وأنشئ تطبيقاً جديداً.
2. من تبويب **Bot** فعّل الصلاحيات التالية (Privileged Gateway Intents):
   - `SERVER MEMBERS INTENT`
3. من تبويب **OAuth2 → URL Generator** اختر `bot` و`applications.commands`،
   وامنح الصلاحيات: إدارة الرتب، إدارة القنوات، إرسال رسائل، إدارة Embeds، إضافة تفاعلات.
4. انسخ رابط الدعوة وأضف البوت لسيرفرك.
5. انسخ الـ Token من تبويب Bot (لن يظهر إلا مرة واحدة).

### 2) تجهيز قاعدة البيانات
أنشئ قاعدة بيانات PostgreSQL (يمكنك استخدام Railway مباشرة — يوفرها كإضافة بضغطة زر).

### 3) تجهيز القنوات
أنشئ 3 قنوات في سيرفرك ثم انسخ آيدي كل واحدة (فعّل Developer Mode من إعدادات Discord):
- قناة الدليل (سينشر فيها زر بدء اللعبة)
- قناة الأخبار العالمية (تُنشر فيها نتائج المعارك والأحداث)
- قناة سجلات الأدمن (سجل خاص بكل عمليات الإدارة)

### 4) متغيرات البيئة
انسخ `.env.example` إلى `.env` واملأ القيم:
```
DISCORD_TOKEN=...
DATABASE_URL=...
GUILD_ID=...
ADMIN_LOG_CHANNEL_ID=...
NEWS_CHANNEL_ID=...
GUIDE_CHANNEL_ID=...
```

### 5) النشر على Railway (موصى به)
1. ادفع هذا المجلد لمستودع GitHub.
2. أنشئ مشروعاً جديداً على Railway واربطه بالمستودع.
3. أضف إضافة PostgreSQL — سيملأ `DATABASE_URL` تلقائياً.
4. أضف بقية متغيرات البيئة من الخطوة 4 يدوياً في تبويب Variables.
5. Railway سيستخدم `Dockerfile` و`railway.toml` تلقائياً ويشغّل البوت.

### 6) التشغيل محلياً (اختياري للتجربة)
```bash
pip install -r requirements.txt
python bot.py
```

## 🏰 قنوات كل لاعب

فور ضغط اللاعب **🚀 ابدأ إمبراطوريتك** تُنشأ له فئة (Category) خاصة به وحده تحتوي 5 قنوات
لا يراها أي لاعب آخر:

| القناة | الاستخدام |
|---|---|
| `👑┃king` | ترقية المباني + سجل الأحداث (تحديثات تلقائية كل ساعة) |
| `⚔️┃war` | تدريب، غارات، تجسس، علاج |
| `🔮┃magic` | استدعاء السحرة والمخلوقات، البعثات |
| `📖┃guide` | شرح اللعبة الكامل، مثبّت دائماً في القناة |
| `🤝┃ally` | تأسيس/الانضمام لتحالف، أو حالة تحالفه الحالي وزر مغادرة |

ملاحظة: قناة `📖┃guide` الخاصة باللاعب مختلفة عن قناة الدليل العامة (`GUIDE_CHANNEL_ID`) التي
يضعها الأدمن لعرض زر التسجيل الأول — الأولى شخصية لكل لاعب، والثانية عامة للسيرفر كله.

### قنوات كل تحالف
عند تأسيس تحالف تُنشأ فئة خاصة بأعضائه فقط (`🛡️┃TAG`) تحتوي:
- `🛡️┃hq` — بنك التحالف وطلبات الدعم
- `⚔️┃war-room` — تنسيق الهجمات والدفاعات

وتُمنح رتبة (Role) خاصة بالتحالف لكل من ينضم، وتُسحب تلقائياً عند المغادرة.

## 🎮 بعد التشغيل الأول

داخل ديسكورد، وبصلاحية أدمن، نفّذ الأوامر التالية **مرة واحدة فقط** لنشر اللوحات الثابتة:

| الأمر | أين يُنفَّذ |
|-------|-------------|
| `/setup_guide` | داخل قناة الدليل — ينشر زر «ابدأ إمبراطوريتك» |
| `/setup_alliance_hub` | داخل أي قناة تريدها مركزاً للتحالفات |
| `/setup_market` | داخل أي قناة تريدها سوقاً حرة |

باقي كل شيء (الترقية، التدريب، الغارات، السحر، إلخ) يعمل بالأزرار تلقائياً بعد تسجيل كل لاعب —
لا حاجة لأي أوامر إضافية. الأمر الوحيد المتبقي للاعبين هو `/guide` لشرح اللعبة الكامل.
