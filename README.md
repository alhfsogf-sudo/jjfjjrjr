# 👷 الوزير - أداة بناء سيرفر ديسكورد بالذكاء الاصطناعي (مجاني بالكامل)

بوت مبسّط بغرض واحد: ينفذ أوامر بناء وتعديل هيكلة السيرفر (قنوات،
فئات، رتب، صلاحيات) فور ما تطلبها منه بالعربي الطبيعي - ينفذ فورًا بدون
انتظار تأكيد، ويخبرك بوضوح وش سوى بالضبط.

يعمل على **Cerebras** (نموذج Llama 3.3 70B) - استدلال فائق السرعة على
معالج Cerebras مباشرة، مع خطة مجانية (Free Tier) بدون بطاقة ائتمان.

---

## 🚀 التشغيل على Railway

### 1. إنشاء البوت
1. https://discord.com/developers/applications → New Application → Bot
2. فعّل **MESSAGE CONTENT INTENT** و **SERVER MEMBERS INTENT**.
3. انسخ التوكن (`DISCORD_TOKEN`).
4. OAuth2 → URL Generator → Scope: `bot`، Permission: `Administrator`
   → افتح الرابط وأضف البوت لسيرفرك.

### 2. الأشخاص المصرح لهم
- فعّل وضع المطور بديسكورد → كليك يمين على حسابك → نسخ المعرّف → `OWNER_ID`
- لو فيه شخص ثاني يحتاج صلاحية، ضيف آيديه بمتغير `AUTHORIZED_USER_IDS`
  مفصول بفواصل: `1111,2222`

### 3. مفتاح Cerebras API
1. روح لـ **cloud.cerebras.ai** وسجل حساب.
2. من القائمة اختر **API Keys** → **Create API Key**.
3. انسخ المفتاح وحطه بمتغير `CEREBRAS_API_KEY_1`.
4. (اختياري) لو تبي احتياط أكبر، سوي حسابات إضافية واحصل على مفاتيح
   ثانية لـ `CEREBRAS_API_KEY_2` وحتى `5` - البوت يتنقل بينهم تلقائيًا
   لو انتهت حصة أي مفتاح.

**حصة Cerebras المجانية تتغير من وقت لآخر** - تأكد من صفحة التسعير
(cerebras.ai) لمعرفة الحد اليومي الحالي على نموذج Llama 3.3 70B.

### 4. الرفع على Railway
ارفع هذا المجلد كامل، وأضف بتبويب **Variables**:
```
DISCORD_TOKEN=توكن_البوت
OWNER_ID=آيدي_الشخص_المصرح_له
AUTHORIZED_USER_IDS=(اختياري)
CEREBRAS_API_KEY_1=مفتاحك
```
البوت يشتغل فورًا بدون أي إعداد إضافي.

## 🧠 كيف يستخدمه؟

يبدأ الطلب بكلمة **"الوزير"** بأي قناة يشوفها البوت:

```
الوزير أنشئ فئة اسمها القيادة
الوزير سوي قناة نصية اسمها اوامر داخل فئة القيادة
الوزير أنشئ رتبة اسمها المطورين بلون ازرق
الوزير امنع رتبة المطورين من رؤية قناة اوامر
الوزير اعطي صلاحية ادارة القنوات لرتبة المطورين
الوزير غير اسم قناة كذا الى كذا
الوزير وريني الهيكلة الحالية
```

- **ينفذ مباشرة بدون أي تأكيد**.
- **يتذكر آخر 20 رسالة** من محادثتك معه (بالذاكرة فقط، تنمسح عند إعادة
  تشغيل البوت).
- **فقط الأشخاص المصرح لهم** يقدرون يستخدمونه.

### الصلاحيات المدعومة بالتخصيص (grant/deny/allow)
`manage_channels`, `manage_roles`, `kick_members`, `ban_members`,
`manage_messages`, `send_messages`, `view_channel`, `connect`, `speak`,
`mention_everyone`, `manage_guild`, `manage_webhooks`,
`manage_nicknames`, `administrator`, `attach_files`, `add_reactions`,
`mute_members`, `move_members` - تقدر تطلبها بالعربي أو بالاسم الإنجليزي.

## 🔧 التشغيل محليًا (اختياري)
```bash
pip install -r requirements.txt
cp .env.example .env   # عبّي القيم
python bot.py
```

## ⚠️ ملاحظات مهمة
- رتبة البوت بالسيرفر لازم تكون **أعلى** من أي رتبة يبي يديرها أو يعدلها.
- Message Content Intent و Server Members Intent لازم مفعّلين من
  Developer Portal وإلا البوت ما يشتغل.
- ما فيه قاعدة بيانات أو تخزين دائم - أداة تنفيذ فورية بس.
- **جودة الفهم**: Llama 3.3 (المستخدم هنا) قوي جدًا بالمهام الإنجليزية
  والعربية البسيطة والمباشرة، لكنه أضعف شوي من نماذج مدفوعة زي Claude
  بفهم الطلبات العربية المعقدة أو الملتوية. لأفضل نتيجة، خلي طلباتك
  للوزير واضحة ومباشرة.
- لو حصل خطأ "تعذر الوصول للذكاء الاصطناعي" يعني كل مفاتيحك تجاوزت
  الحصة اليومية المجانية - انتظر لليوم التالي أو ضيف مفتاح جديد.
- Cerebras أسرع بكثير من Groq بالاستدلال (آلاف التوكنز بالثانية) بفضل
  معالجها Wafer-Scale المخصص.
